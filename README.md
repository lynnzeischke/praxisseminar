# Praxisseminar Employee AI Readiness

Begleitmaterial zur Hausarbeit von Lynn Zeischke. Stand: 30.10.2026.

## Inhalt

- [Chatverläufe](Chatverlaeufe/): 24 historische Exporte und 20 ergänzende Läufe als lesbare Markdown-Dokumente.
- [Promptversionen](Promptversionen/): alle 50 dokumentierten Promptdateien einschließlich R6.2; identische Format- und Ablagevarianten bleiben erhalten.
- [Wissenschaftliche Paper](Wissenschaftliche_Paper/): neun unveränderte PDFs mit dokumentierter Creative-Commons-Lizenz; AISES ist über den Publikationslink erschlossen.

Die Hausarbeit wird separat abgegeben. Dieses Repository dokumentiert Entwicklung und Modellausgaben; es belegt keine psychometrische Validierung des Fragebogens. R6.2 bleibt TEST_CANDIDATE.
